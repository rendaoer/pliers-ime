# 英文候选的"开发常用词"补充表（一行一个词或一串词，# 开头是注释）。
#
# 为什么需要它：内置的通用词频表来自影视字幕（OpenSubtitles），口语词排得很前，
# 而 `config`、`stdout`、`iterator`、`kubernetes` 这些要么根本没有、要么排到两万名开外。
# 这份表里的词会被插到通用表最常用的 1000 个词之后、其余词之前 ——
# 也就是"日常英语里最常用的一千个词照样赢，剩下的位置让给开发词"。
#
# 排序**有意义**：同一个前缀下先写的先出（敲 `imp` 先出 import 还是 image，
# 就看谁写在前面）。所以按"敲这个前缀时最可能想要哪个词"来排，别按字母表排。
#
# 这个文件是本项目自己写的（MIT OR Apache-2.0），不涉及第三方词表版权。
# 想加自己的词**不用改这里** —— 在配置里写 [english] path = "~/..../words.txt"，
# 那份词表会排在所有内置词前面。见 docs/config.md。
